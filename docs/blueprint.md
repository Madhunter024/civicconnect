# **App Name**: Civic Connect

## Core Features:

- Issue Reporting: Mobile-first reporting of civic issues using photo capture, GPS tagging, and voice/text descriptions.
- Automated Issue Categorization: Use a tool to Automatically categorize reported issues using generative AI to streamline department assignment. 
- Real-time Issue Mapping: Display reported issues on a live Google Maps interface.
- Department Assignment: Route issues to the relevant departments based on categorization.
- Status Tracking: Enable citizens to track the progress of their reported issues.
- Admin Analytics Dashboard: Provide administrators with access to analytics on issue resolution and departmental performance.
- Notifications: Keep users informed via Firebase and Email notifications for updates on their issues.

## Style Guidelines:

- Primary color: Deep sky blue (#3299CC) to evoke trust, reliability, and civic responsibility.
- Background color: Light gray (#EEEEEE) to provide a clean, neutral backdrop.
- Accent color: Soft orange (#E59400) for CTAs and highlights to draw attention without overwhelming the user.
- Body and headline font: 'PT Sans', a humanist sans-serif combining modern and warm feeling for ease of readability
- Use clear, recognizable icons to represent issue categories.
- Mobile-first responsive layout for accessibility across devices.
- Subtle animations to indicate status changes and updates.
